Eight new themes of Kadal's own, each an npm package with its own layouts and components, light and dark, print-safe and checked for contrast: **ocean** (Kadal's sea, calm gradients, a wave cover and depth-gauge section openers), **folio** (an editorial serif for essays and keynotes: pull-quotes, a drop-cap essay column, chapter openers), **swiss** (a strict grid, huge grotesk headings and one signal colour, with a running header), **terminal** (mono-forward and dark first, code blocks as editor windows, a `<Terminal>` session component), **lecture** (numbered sections, a course footer, theorem / definition / proof blocks, citations and a references slide), **brand** (colours, logo and footer from `themeConfig` alone, with title, agenda and metrics layouts), **crayon** (pastel stickers and speech bubbles for workshops and classrooms) and **neon** (synthwave for launches, with a solid print fallback). Install one and name it: `npm i @kadal/theme-ocean`, `theme: ocean`. The hosted player bundles them all.

Also: a theme picked from the theme menu now loads its own fonts, instead of wearing the deck theme's.
