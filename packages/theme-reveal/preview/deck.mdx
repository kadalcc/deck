## Hello There

reveal.js enables you to create beautiful interactive slide decks using HTML. This presentation
will show you examples of what it can do.

---

## Pretty Code

```js
import React, { useState } from "react";

function Example() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>Clicked {count} times</button>;
}
```

Code syntax highlighting courtesy of [highlight.js](https://highlightjs.org/usage/).

## Point of View

Press **ESC** to enter the slide overview.

- Hold down the **Alt** key and click on any element to zoom towards it
- Lists _keep_ their bullets left-aligned
  - and nest one level deeper
- Even with `inline code`
