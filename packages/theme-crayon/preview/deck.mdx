# Crayon

A playful pastel theme for workshops and classrooms: rounded shapes, a friendly face, and sticker-like callouts.

---

## Body text, lists and links

A paragraph in the body face sets the rhythm for everything else: **strong words**, *emphasis*, `inline code`, a [link to the docs](https://deck.kadal.cc/docs/) and a key, <Kbd>T</Kbd>, for the theme menu.

- A first point, kept to one line
- A second, with a nested list
  - which sits one step in
  - and stays quieter
- A third, to end on

## Code, with a title and highlights

```ts {2-4|6}{lines:true} [tide.ts]
export function tide(hour: number): number {
  // two highs and two lows a day, more or less
  const period = 12.42;
  return Math.sin((hour / period) * 2 * Math.PI);
}
export const high = tide(6.21) > 0.99;
```

A highlighted range, line numbers, and the file's name in the bar.

3. **Show a friend** Press <Kbd>S</Kbd> for the presenter view.
