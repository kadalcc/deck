#### Kadal Deck · the theme gallery

# Eight looks, one deck

Press <Kbd>T</Kbd> and pick a theme: the words stay, the look changes.

---

## The themes

| Theme | For | Package |
| --- | --- | --- |
| **ocean** | Kadal's own: the sea, calm gradients | `@kadal/theme-ocean` |
| **folio** | essays and keynotes: paper and serif | `@kadal/theme-folio` |
| **swiss** | design talks: grid, grotesk, one signal | `@kadal/theme-swiss` |
| **terminal** | code-heavy talks: mono, dark first | `@kadal/theme-terminal` |
| **lecture** | teaching: sections, theorems, print | `@kadal/theme-lecture` |
| **brand** | companies: colours and logo from themeConfig | `@kadal/theme-brand` |
| **crayon** | workshops and classrooms: pastel stickers | `@kadal/theme-crayon` |
| **neon** | meetups and launches: synthwave, dark | `@kadal/theme-neon` |

---

## Writing in any theme

A paragraph sets the rhythm: **strong words**, *emphasis*, `inline code` and a [link](https://deck.kadal.cc/docs/).

- Install a theme: `npm i @kadal/theme-folio`
- Name it in the headmatter: `theme: folio`
  - or offer several: `themes: [folio, ocean]`
- Brand it with `themeConfig`, never with CSS

> A theme is a look, not a rewrite: the same deck.mdx wears all eight.

---

## Code

```ts {2-3}{lines:true} [deck.config.ts]
export default {
  theme: "terminal",
  themeConfig: { accent: "#aad94c" },
};
```

<Callout kind="tip" title="Code colours">They come from the deck's own theme (its `kadal.theme.shiki`), highlighted when the deck is built: here, Ocean's Night Owl in every theme.</Callout>
