## Types, from the compiler

<Cols cols="1.3fr 1fr" gap="2rem" align="start">
<Col>

```ts twoslash
interface Tide {
  height: number
  at: Date
}

const low: Tide = { height: "0.4", at: new Date() }

const high = { height: 6.1, at: new Date() } satisfies Tide
//    ^?
```

</Col>
<Col>

Hover a name — or press <Kbd>Tab</Kbd> to it — for its type. Errors arrive underlined, with the compiler's own words; `// ^?` pins a type open.

<How>

````mdx
```ts twoslash

```
````

</How>

</Col>
</Cols>

<Notes>
TwoSlash runs the TypeScript compiler while the deck builds: every identifier carries its real type, errors are the compiler's, and a caret query pins one open. Nothing of TypeScript reaches the audience — it is HTML.
</Notes>

## Run it, see it

```ts {monaco-run}{showOutputAt:'+1'} [tides.ts]
const heights = [0.4, 2.8, 6.1, 3.3]
const high = Math.max(...heights)
console.log(`high water: ${high} m`, { at: heights.indexOf(high) })
await new Promise((r) => setTimeout(r, 300))
console.log(heights.map((h) => (h / high).toFixed(2)))
```

<p className="sc-small"><code>{"{monaco-run}"}</code>: JavaScript and TypeScript run in a Web Worker (with a timeout), Python in Pyodide, anything else through <code>registerCodeRunner</code>. <kbd>Ctrl</kbd>/<kbd>⌘</kbd>+<kbd>Enter</kbd> runs; edits re-run.</p>

<Notes>
A runnable block: the code runs as the slide arrives and again on every edit, in a worker that a timeout can stop. Its output waits for a click here — showOutputAt plus one.
[click] And there it is: console output, objects printed the way a console prints them.
</Notes>

## Maths, typeset at build time

<Cols cols="1.1fr 1fr" gap="2.5rem" align="start">
<Col>

Inline, between dollars: the tide height is $h(t) = A\cos(\omega t + \varphi)$.

Display, between double dollars:

$$
\omega = \frac{2\pi}{T}, \qquad T \approx 12\,\text{h}\;25\,\text{min}
$$

From JSX, where Markdown cannot reach:

<Tex block tex="\int_0^{T} h(t)\,dt = 0" />

</Col>
<Col>

<How>

```mdx
$h(t) = A\cos(\omega t + \varphi)$

$$
\omega = \frac{2\pi}{T}
$$

<Tex block tex="\int_0^{T} h(t)\,dt = 0" />
```

</How>

</Col>
</Cols>

<Notes>
KaTeX, at build time: the slide arrives as HTML, so maths costs the audience nothing to render. `<Tex>` — also exported as `<Math>` — is for maths inside components, where the dollar syntax does not reach.
</Notes>
