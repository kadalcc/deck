## One of your own

`rise` is not built in: the headmatter names two keyframes for it under `transitions:`, and one more pair for going back.

<How>

```yaml
transitions:
  rise:
    in: sc-rise-in
    out: sc-rise-out
    back: { in: sc-rise-in-back, out: sc-rise-out-back }
```

</How>

<Notes>
A custom transition defined in the headmatter: the keyframes live in this deck's stylesheet, and `transitions:` gives them a name any slide can use. Going back plays the `back` pair. Speeds, reduced motion and print treat it as they treat the built-in ones.
</Notes>

## This slide moves on by itself

<p className="sc-countdown"><Timer seconds={6} /></p>

`autoSlide: 6000` in its frontmatter: six seconds, then the next slide. <Kbd>A</Kbd> pauses and resumes; a click anywhere stops it.

<Notes>
Auto-slide. A deck can set `autoSlide` for every slide — a kiosk, a loop in a foyer — or a single slide can, like this one: six seconds and it moves on. A pauses it; any click stops it. On a deck that sets nothing, A still starts a gentle five-second advance.
</Notes>
