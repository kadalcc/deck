# A Kadal Deck

```sh
npm install
npm run dev          # http://localhost:5173 — edit deck.mdx and watch it reload
npm run build        # dist/, for any static host
npx kadal-deck login && npx kadal-deck publish   # a URL, with a live room for your audience
```

Press `?` in the deck for every key, `P` for the presenter view. Docs: https://deck.kadal.cc/docs/
