# My first Kadal Deck

Slides are Markdown. Press <Kbd>→</Kbd> or <Kbd>Space</Kbd> to move, <Kbd>?</Kbd> for every key.

<Notes>
  Speaker notes live in a `Notes` block. Press <Kbd>P</Kbd> to open the presenter view: notes,
  a timer and the next slide, in its own window.
</Notes>

# Three dashes start a new slide

Four dashes (`----`) start a slide below this one: a vertical column, as in reveal.js.

----

## Below the section

Use vertical slides for detail a talk might skip. <Kbd>↓</Kbd> goes down, <Kbd>→</Kbd> goes on.

---

## Points, one click at a time

<Clicks>

- Wrap a list in `<Clicks>` and each item waits for a click
- Notes can follow along: put `[click]` where each one starts
- The presenter view highlights the matching note

</Clicks>

<Notes>[click] The first point. [click] The second. [click] And the third.</Notes>

---

## Code that steps through itself

```ts {1|2-4|all} [ask.ts]
const answer = 42;
export function ask(question: string) {
  return `${question}? ${answer}`;
}
```

The `{1|2-4|all}` after the language highlights those lines, one click each.
